# 🎬 Movie Ticket Booking System

A movie seat booking app built with dynamic seat selection, availability tracking, and confirmation logic.

## 🌟 Features
- Interactive seat selection
- Availability tracking
- Color-coded seat status (booked, selected, available)
- Total cost calculation

## 🛠️ Tech Stack
- HTML
- CSS (for seat styling)
- JavaScript

### 🔗 Live Demo
[Click here to view the live website](https://sravyabulusu.github.io/Movie_project/)

## 🚀 How to Run Locally
1. Clone the repo
2. Run `npm install` and `npm start` for React project
