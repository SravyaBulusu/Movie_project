# Theatre Booking System 🎭

A **frontend web application** to book theatre seats, view available shows, and manage seat selection in real-time. Built entirely with **HTML, CSS, and JavaScript**.  

---

## 🌐 Live Demo
Check out the project live:  
<a href="https://sravyabulusu.github.io/Movie_project/">Click here to open in a new tab</a>

---

## 💻 Features
- **View shows** with available seat layout.
- **Select and book seats** interactively.
- **Responsive design** for desktop and mobile devices.
- **Real-time seat selection updates** using JavaScript.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Hosting:** Netlify / GitHub Pages (if applicable)
